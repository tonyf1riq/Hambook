Notice d'utilisation — HamBook
Version 1.7.1 · 28 octobre 2026 · Carnet de trafic radio
HamBook est un carnet de trafic radio 100 % web, sans installation, fonctionnant entièrement dans le navigateur. Toutes les données sont stockées en local (localStorage). Aucune donnée n'est envoyée sans votre accord explicite.
📡 1. Saisie d'un QSO
IndicatifIndicatif de la station contactée. Mise en majuscules automatique. Avertissement si déjà loggué.
PrénomPrénom de l'opérateur distant. Rappelé automatiquement si indicatif déjà connu.
BandeFréquence et mode suggérés automatiquement selon la bande choisie. Le RST s'adapte (59 Phone / 599 CW-Digital).
Freq (MHz)Fréquence en MHz. Pré-remplie selon la bande. Modifiable librement.
ModeFM, LSB, USB, CW, FT8, FT4, WSPR, JS8, RTTY, PSK31, AM, DMR, C4FM, D-STAR.
RST T/RRapport émis / reçu. Défaut configurable (59 ou 599).
LocatorLocator Maidenhead de la station distante. Distance et azimut calculés automatiquement. Accepte aussi un nom de ville → géocodage Nominatim.
NoteCommentaire libre, exporté dans le champ ADIF <COMMENT>.
🌿 POTARéférence parc optionnelle (ex : FR-0001, K-4570, DL-0042, VK-0001). Si l'activateur est en ligne, le panneau spot s'affiche et remplit automatiquement fréquence, bande et mode. Sélection Chasseur / Activateur.
⏎ Appuyez sur Entrée dans le champ Indicatif pour enregistrer rapidement. L'heure UTC est capturée automatiquement.
☀️ 2. Thème jour / nuit
Le thème bascule automatiquement selon l'heure locale :
☀️ Jour
06h00 – 20h59
Thème clair
🌙 Nuit
21h00 – 05h59
Thème sombre
Le bouton icône lune / soleil dans le header force le thème et mémorise votre choix (clé HamBook_Theme). Pour revenir au mode automatique, supprimez cette clé dans le localStorage.
🔍 3. Recherche et log
La barre de recherche filtre en temps réel sur l'indicatif, la bande, le mode, le locator, la date, la note et la référence POTA. Les tokens sont séparés par des espaces (recherche multi-critères cumulée).

Chaque ligne affiche : date, heure UTC, callsign (lien QRZ.com), fréquence colorée par bande, mode, locator, distance/azimut et référence POTA cliquable vers pota.app.
💾 4. Export / Import
JSONSauvegarde complète, ré-importable dans HamBook.
ADIF .adiFormat universel radio (WSJT-X, Log4OM, Ham Radio Deluxe…). Import et export. Champs POTA exportés (<SIG> / <MY_SIG>). Doublons ignorés à l'import.
Cabrillo .cbrFormat concours. Import et export.
🔄 5. Synchronisation externe
WavelogURL + clé API + Station ID. Chaque QSO loggué est envoyé en temps réel via l'API ADIF.
Club LogEmail + mot de passe + indicatif. Upload ADIF en temps réel via realtime.php.
HRDHam Radio Deluxe Logbook API locale (localhost:7171). Nécessite HRD actif sur le même poste.
LoTWTest de connexion uniquement (CORS bloqué). Upload réel via tqsl avec certificat .p12 ARRL.
eQSL.ccUpload ADIF direct par QSO via l'API eQSL. Identifiant + mot de passe requis.
📡 HamAlertSpot DX via l'API HamAlert. Bouton 📡 Spotter dans le formulaire. Clé API requise (hamalert.org → Settings → API). Envoie callsign, fréquence (kHz), mode et commentaire.
𝕏 / DiscordPublication automatique à chaque QSO. Modèles personnalisables avec variables {call} {band} {mode} {freq}…
⚙️ 6. Configuration
Accessible via le bouton engrenage en haut à droite. Sections : Station (indicatif, locator, QTH, matériel), Préférences (bande + RST par défaut), Synchronisation, Partage social, Export automatique.

La configuration peut être exportée / importée en JSON (HamBook_config.json) pour sauvegarder ou migrer vers un autre navigateur/poste.
🌤️ 7. Météo et propagation
Météo : données Open-Meteo (température, vent, pression, précipitations, visibilité). Actualisées toutes les 10 minutes.

Propagation : indices SFI, SN, A et K depuis HamQSL/NOAA. Actualisés toutes les 15 minutes.
⌨️ 8. Raccourcis clavier
EntréeLogger / valider le QSO (depuis le champ Indicatif).
ÉchapFermer la notice ou la configuration.
🔒 9. Données et vie privée
Tout est stocké dans le localStorage de votre navigateur. Aucun serveur HamBook. Les appels externes sont : Open-Meteo (météo), HamQSL (propagation), POTA API (spots), Nominatim (géocodage optionnel). Vos mots de passe de synchronisation sont stockés localement en clair.
🔠 10. Taille de la police
Le header comporte un contrôle A− / 100% / A+ qui ajuste la taille de la police (85% / 100% / 115% / 130%), mémorisé sous HamBook_FontScale.
